Экспорт ZhibekBank на GitHub

Пошаговая инструкция для публикации на GitHub Pages

Скачать готовый HTML файл
Самодостаточный единый файл index.html со всеми стилями и скриптами

Команды для публикации через Git Terminal:

# 1. Создайте папку и перейдите в нее
mkdir zhibek-bank && cd zhibek-bank
# 2. Поместите downloaded index.html в эту папку и инициализируйте git
git init
git add index.html
git commit -m "Initial commit of ZhibekBank website"
# 3. Привяжите ваш репозиторий GitHub
git branch -M main
git remote add origin https://github.com/ВАШ_USERNAME/zhibek-bank.git
git push -u origin main

Активация GitHub Pages (Бесплатный хостинг):

  1. Зайдите в репозиторий на GitHub в браузере.
  2. Перейдите в Settings -> Pages.
  3. В графе Source выберите ветку main и папку / (root).
  4. Нажмите Save. Ваш сайт будет доступен по адресу: https://username.github.io/zhibek-bank/.
